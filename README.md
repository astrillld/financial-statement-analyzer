# Financial Statement Analyzer

A Python project for analyzing financial statement data and detecting unusual patterns in company performance.

## Overview

This project simulates a simple audit-style financial analysis workflow. It reads financial data from a CSV file, calculates key financial metrics, identifies anomalies, and visualizes financial trends.

The goal of the project is to demonstrate analytical thinking, data processing, and business-oriented problem solving using Python.

## Features

- Loads financial data from a CSV file
- Calculates:
  - profit margin
  - expense ratio
  - revenue growth
  - profit growth
- Detects anomalies such as:
  - significant profit drops
  - unusual expense spikes
  - significant revenue drops
  - low profit margins
- Prints a financial analysis report in the terminal
- Generates a line chart for revenue, expenses, and profit

## Technologies Used

- Python
- pandas
- matplotlib
